The very blog site you're on! Sure it's kind of cheating to include this here, but it is a project afterall.

As you might've seen on the footer of the page, this site was made using [Jekyll](https://jekyllrb.com/) which is hosted on GitHub Pages. Not only did I wanted the chance to try it out, but it made sense as I am hosting my projects on GitHub.

The goal with this was to make it as lightweight as possible and not as flashy compared to my portfolio site.

HTML with Liquid, Sass, and Markdown files are used throughout the site. Since Sass is already implemented in Jekyll without extra configuration I figured there was no harm in saving my fingers the extra trouble of not having to put in some curly brances, and commas.

The theme is custom, built from the ground up.

Plugins used:

- [`jekyll-minifier`](https://github.com/digitalsparky/jekyll-minifier) - Used to, well, minify everything to reduce the file size. Applies to HTML and CSS.

- [`jekyll-paginate`](https://github.com/jekyll/jekyll-paginate) - Displays all of my posts in multiple pages instead of all at once in the front page.

- [`jekyll-target-blank`](https://github.com/keithmifsud/jekyll-target-blank) - Makes all external links open a new tab.
