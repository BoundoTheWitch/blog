Isabelle Bot

13 Oct 2026

Isabelle Bot is a bot created with Discord.js for a friend’s Discord server.

First made in 2018 as a fun little project to copy some of the functions of my friend’s Twitch bot of the same name, Isabelle Bot was expanded from doing simple commands to being able to audit edited and deleted messages, then community-based activities was added using what the community called “Star Board.”

This is where I’ve put the most blood, sweat, and tears into on any programming-related project I’ve ever worked on. It’s thanks to this project that I’ve learned a lot of the advanced JavaScript that I know today, some of the better practices when making a JS app, learning some backend development, and it’s how I learned how to use SQLite.

There are some flaws that I have not been able to get around to polish, such as properly implementing Promises without a hacky solution. At the time I had only just started learning Promises and I’ve been meaning to go back and clean up everything.

In the repo I have provided more detailed explanations for the basic commands, and how the audits worked, as well as how the Star Board system worked for both the reading and workout sections.

I have not had the time to update her in a long time due to some personal issues I’ve been facing in my life.
